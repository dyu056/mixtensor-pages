搜索方式测试 MSE相对基线改善胜过基线的 trial不同入选架构

每个 trial 在 24 个候选中查询 8 个架构，每次查询使用两个训练种子；前 2 个查询相同，之后分别按元模型排序、统计回归排序或随机顺序选择。最终使用 3 个新种子重训。图元模型预热数据有额外成本。

评测边界

  • 所有架构采用 300 steps、batch 64、width 16；参数量及实际计算量仍可能不同。
  • 图的训练 / 验证 / 候选划分按子图家族进行。同一结构的训练种子不跨集合。
  • 候选预测冻结后才查询候选验证标签，入选架构冻结后才访问保留测试集。
  • trial 之间重复使用候选和入选架构，不能当作独立重复，也未声明统计显著性。
  • V1 未超过基线后，V2 预先固定扩大为 512 个架构，使用新的测试样本。属于后续探索实验。
  • 节点 attention 权重没有被解释为因果贡献。本阶段先验证预测与搜索效果。
