# mixtensor Pages

Public static website for mixtensor. This repository contains the `docs/` website snapshot only.

- [Module Definition](https://dyu056.github.io/mixtensor-pages/)
- [DSL primitives](https://dyu056.github.io/mixtensor-pages/primitives.html)
- [Model decompositions](https://dyu056.github.io/mixtensor-pages/models.html)
- [Graph IR](https://dyu056.github.io/mixtensor-pages/graph-ir/)
- [Random models](https://dyu056.github.io/mixtensor-pages/random-models/)
- [Random model results](https://dyu056.github.io/mixtensor-pages/random-models/results.html)

GitHub Pages publishes the `/docs` folder on `main`. All paths are relative, and assets are served locally. `.nojekyll` preserves Python source snapshots and static files without a Jekyll build.
